# Titanic Survival — Preprocessing Pipeline and Cleaned Dataset

## Objective
Median imputation, scaling and one-hot encoding in a reusable preprocessing pipeline.

## Dataset
Compact offline CSV included for immediate execution. Full public source: https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

## Steps
1. Load and inspect data
2. EDA and preprocessing
3. Train requested model
4. Evaluate metrics
5. Interpret graph/results
